# calculadoraCoordenadas — Calculadora de puntos

**Creadores:**
- Anahí Hernández — [@annyie681](https://github.com/annyie681)
- Sebastián Ibarra — [@sebastianibar](https://github.com/sebastianibar)
- Josué Martínez — [@Lalocarrito](https://github.com/Lalocarrito)
- Celeste Román — [@mceless3](https://github.com/mceless3)

Programa de escritorio en Java que convierte puntos entre sistemas de coordenadas (2D y 3D)
y calcula distancias entre dos puntos, con diálogos de Swing.

## Requisitos y ejecución

- JDK 8 o superior

```bash
javac calculadoraEmergent.java
java calculadoraEmergent
```
